# TikerTalk – AI-Powered Financial Insights Agent

TikerTalk is an AI-powered financial insights application that allows users to ask questions about stocks and financial data in natural language.

## How It Works

```text
User Query
    ↓
LLM interprets the request
    ↓
Tool / Function Selection
    ↓
Financial Data API
    ↓
Retrieved Market Data
    ↓
LLM Analysis
    ↓
Financial Insight
```
## Key Features

- Natural-language financial queries
- LLM-based tool/function calling
- Financial data retrieval through APIs
- LLM-generated financial insights
- Streamlit-based interactive interface
- Error handling for API failures and unexpected responses

## Tech Stack

- Python
- OpenAI API
- Function Calling
- RapidAPI / Yahoo Finance
- Streamlit
